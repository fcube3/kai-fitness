# PRD — Kai Fitness

## Problem
Feng logs workouts in Apple Notes with a specific format. He needs a visual dashboard to track progression, spot weaknesses, and see PRs — without using a bloated fitness app.

## User
Feng (sole user, trains 4-5x/week).

## Goals
- Auto-import from Apple Notes format
- See exercise weight progression over time
- Track PRs and identify stalled lifts
- Browse all sessions with search/filter

## Non-Goals
- Social features
- Cardio/nutrition tracking
- Training program generation

## Success Metrics
- All workout notes parsed correctly (>95% parse rate)
- PR board accurate and current
- Import runs reliably via cron
